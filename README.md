# Football Career: Become a Legend — Python prototype (Stage 1)

## Run in Pydroid 3
1. Extract the ZIP into a folder named `FootballCareer`.
2. Open `main.py` in Pydroid 3.
3. Press Run.
4. Create a career, inspect the dashboard, test the calendar clock, then save/load.

## Run tests
From the project folder:
```bash
python -m unittest discover -s tests -v
```

## Scope note
This is foundation code, not a complete game. No real-world dataset is bundled: source selection, licensing and provenance must be resolved first. No gameplay ratings or formulas are invented. See `docs/` before extending.
